# LazyASF — пульт для телевизора с дивана

Две программы:

| Где | Что | Файл |
|---|---|---|
| Ноутбук (Windows) | сервер: экран, Bluetooth, звук, Chrome, мышь | `dist/LazyASF-PC/LazyASF.exe` |
| Телефон (Android 8+) | пульт: 3 кнопки сайтов, тачпад, таймер сна | `dist/LazyASF-phone.apk` |

## Первый запуск

1. **Ноут:** запусти `dist/LazyASF-PC/LazyASF.exe`. Если Windows спросит про брандмауэр — разреши
   для частных сетей. Если телефон всё равно не видит ноут — запусти `allow-firewall.cmd` от имени администратора
   и проверь, что домашняя Wi-Fi сеть в Windows отмечена как **Частная**.
2. **Телефон:** скинь `LazyASF-phone.apk` на телефон и установи (разреши установку из неизвестных источников).
3. Открой приложение: ноут найдётся сам → введи 4-значный код из окна на ноуте. Код нужен один раз.
4. В окне ноута можно включить «Запускать вместе с Windows» — тогда он будет ждать телефон из трея.

## Что происходит по кнопке YouTube / Boosty / kino.watch

1. Телефон выключает свой Bluetooth (чтобы наушники освободились). Android один раз спросит разрешение
   «Устройства поблизости», некоторые прошивки ещё спрашивают «Разрешить выключить Bluetooth?».
2. Ноут: **«Только второй экран»** (телевизор) → открывает сайт в Chrome под профилем «Илья Сериков»
   на весь экран → включает Bluetooth → подключает выбранные наушники → делает их устройством звука по умолчанию.
3. Телефон сам открывает тачпад. Ход настройки видно на главном экране и в чипе наверху тачпада.

**«Вернуть всё»** — наушники отпускаются, звук/экран/Bluetooth ноута как было, Bluetooth телефона включается обратно.

**Таймер сна** — по истечении: пауза → «Вернуть всё» → попытка выключить ТВ по сети → ноут засыпает
(`sleepTimerPowerAction` в config.json: `sleep` | `hibernate` | `shutdown` | `none`).
Телефон сам включит свой Bluetooth через ~20 с после срабатывания.

## Тачпад

- Вверху квадраты **ЛКМ / ПКМ**: держишь — кнопка зажата (можно тащить, водя другим пальцем по панели).
- 1 палец — курсор (с ускорением), тап — клик; 2 пальца — колёсико, тап двумя — ПКМ.
- Кнопки: ⏪ ⏯ ⏩ (стрелки и медиа-клавиша), ⛶ — `F` (полный экран видео, долгое нажатие — `F11`), Esc,
  громкость, клавиатура (текст на ТВ, Enter, Tab, адресная строка), «назад» в браузере, закрыть вкладку.
- Скорость курсора/прокрутки и прочее — в настройках (иконка вверху главного экрана).

## Настройки ноута — `dist/LazyASF-PC/config.json`

Создаётся при первом запуске. Важное: `sites` (адреса сайтов), `defaultHeadphones`, `chromeProfileName`,
`youtubeExtension`, `tv.ip`, `sleepTimerPowerAction`. Кнопка «config.json» в окне открывает его.
После правки — перезапусти LazyASF (Выход в меню трея).

## Если что-то не работает

- `LazyASF.exe --diag` → пишет в `log.txt` экраны, Bluetooth, аудиоустройства, профиль Chrome.
- Весь журнал — `dist/LazyASF-PC/log.txt` и окно программы.

## Пересборка

Один раз: `powershell -ExecutionPolicy Bypass -File tools/setup-android-sdk.ps1` — скачает JDK 17, Android SDK и Gradle
в `_sdk/` (≈2 ГБ, без админки). Нужен ещё .NET 8 SDK.
Дальше: `powershell -ExecutionPolicy Bypass -File tools/build-all.ps1` → готовое в `dist/`.

Исходники: `desktop/LazyASF.Desktop` (.NET 8, WinForms + Kestrel), `android/` (Kotlin, Jetpack Compose).
